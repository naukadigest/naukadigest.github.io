# Ежедневные газеты — naukadigest.github.io

На сайте несколько газет, у каждой свой адрес (список и настройки — `site.yml` → `editions`):

| Газета | Адрес | Номера |
|---|---|---|
| «Научный дайджест» (Ильназ) | `/ilnaz/` | `content/ilnaz/` |
| «Утренний дайджест» (Рустем, заготовка) | `/rustem/` | `content/rustem/` |

Корень сайта — пустая страница.

Каждое утро Claude собирает номер и кладёт его в `content/<газета>/ГГГГ-ММ-ДД.md`.
После push в `main` GitHub Actions собирает сайт (`build.py`) и публикует его на GitHub Pages — без одобрения.

- Главная газеты (`/ilnaz/`) — список всех номеров по порядку, свежий номер последним; каждый номер — `/ilnaz/issues/ГГГГ-ММ-ДД/`.
- Рубрики — `/ilnaz/rubric/<slug>/`. RSS нет.
- Настройки газеты (название, рубрики, цвета, дата первого номера, текст «О газете») — в её блоке `editions` в `site.yml`. Новая газета = новый блок + папка `content/<slug>/`.
- Номер выпуска считается автоматически: дней с `first_issue` газеты + 1.
- Убрать номер с сайта — удалить файл или добавить `draft: true`.

Локальная проверка: `pip install markdown pyyaml jinja2 && python build.py`.

## Формат номера

Весь номер — один YAML-блок между `---`. Текст после блока (необязательно) выводится курсивом под «Главным за сутки».

```yaml
---
date: 2026-10-25
headline:                       # «Главное за сутки» — ровно 3 строки
  - Первое предложение.
  - Второе предложение.
  - Третье предложение.
news:                           # все заметки номера, в порядке показа внутри рубрики
  - rubric: ai                  # slug рубрики этой газеты (site.yml); у Ильназа: ai | robots | bio | hitech | space | code | logistics
    title: "Заголовок без кликбейта"
    text: |
      3–4 предложения: что сделали → результат с цифрой → почему важно → ограничения.
    status: Рецензируемая статья   # Рецензируемая статья | Препринт | Официальный релиз
    source: "Nature, 21.10"        # подпись ссылки на первоисточник
    url: https://www.nature.com/articles/...
    doi: 10.1038/s41586-026-11132-z   # без https://doi.org/ (необязательно)
    dates: "онлайн 12.10, в печатном номере 23.10"   # необязательно
    also:                          # дополнительные ссылки (необязательно)
      - title: Nature News
        url: https://www.nature.com/articles/...
empty:                          # рубрики без новостей (необязательно; по умолчанию
  robots: За сутки значимых публикаций нет.   # «За сутки значимых публикаций нет.»)
figure:                         # «Цифра дня»
  value: "2 000+"
  text: гамма-всплесков зарегистрировала обсерватория Swift за 22 года
further:                        # «Почитать глубже», 1–2 ссылки
  - title: "Anthropic: подробный разбор"
    url: https://...
---
```

Строки с двоеточием, кавычками или начинающиеся с `«`, `[`, `*` бери в двойные кавычки; внутри двойных кавычек используй «ёлочки». В `text` и `title` можно Markdown (*курсив*, [ссылка](https://...)).
